# QC Cards

A touch-first way to look at apple receiving QC. Each load ticket's pressure, starch and soluble solids are shown as a fan of cards: groups first (variety, grower, lot, source or day), then the loads inside a group, then a single ticket with every fruit sampled.

Built for iPad first, and works on phones and desktops. It is one `index.html` with no build step and no dependencies.

## Live

https://trentonb.github.io/qccards/ is served by GitHub Pages from `main`, so every push updates it within a minute or two. On an iPad or iPhone, open it in Safari and use Share → Add to Home Screen.

## Run it locally

```bash
python -m http.server 8124
```

Then open http://localhost:8124. To use it from an iPad on the same network, open `http://<this-computer's-ip>:8124`. Offline use and one-tap install need the page served over https.

## Data

The data is invented for now. It is generated by `buildMockTickets()`, and everything reads it through `loadTickets()` in `index.html`. Replace the body of `loadTickets()` with a fetch of the real feed. Each ticket needs:

- ticket number
- lot and block
- grower and source (captive or outside)
- variety
- received date and time
- bins
- the sampled fruit readings for pressure (lb), starch (1–6) and soluble solids (°Bx)

Averages and standard deviations are worked out from the samples.

## Using it

- Period: Today, 3 days or 7 days. Drag the glass lens, or tap a single day.
- Circles on the left: group the cards, filter them, and set the order. A long list, such as growers, opens a searchable sheet.
- Views (top bar): save the current setup and come back to it in one tap. Any view can be made Home from the menu.
- Cards: tap to open. Press and slide to move across them. Scroll the mouse wheel over them to step through. Tap empty space to go back a level.
- Table icon: opens every load in scope as a sortable table.
- Menu: save a view, set Home, install on the home screen, change the theme, turn the sound on or off.

Saved views, Home, theme and sound are stored in each browser, so every device keeps its own.

## Placeholders

- The target bands in the ticket detail are the same for every variety. They are waiting for real per-variety spec limits.
- The starch scale is assumed to be 1–6.
